# Linked Numbers
Connect Phone Numbers to Your Agent
Linked numbers allow you to associate phone numbers with your agent for handling inbound calls. When someone calls a linked number, your agent will automatically answer and begin the conversation.
To create new phone numbers for your agents, visit the [Telephony section](https://docs.vogent.ai/platform-overview/telephony).
## 
[​](https://docs.vogent.ai/platform-overview/agents/config/linked-numbers#managing-linked-numbers)
Managing Linked Numbers
  1. Add numbers from your available phone number pool
  2. Remove numbers when you no longer want the agent to handle calls for that line
  3. Transfer numbers between agents as needed


Making changes to linked numbers will affect all future inbound calls to those numbers immediately.
