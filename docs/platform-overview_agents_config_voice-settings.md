# Voice Settings
Configure Your Agent’s Voice and Speech Parameters
Voice settings allow you to customize how your agent sounds during conversations. These settings affect all calls unless overridden via the API.
## 
[​](http://docs.vogent.ai/platform-overview/agents/config/voice-settings#language)
Language
The primary language your agent will use for conversations. This setting should align with your agent’s prompt and intended use case. Currently supported:
  * English
  * Spanish


When setting up your agent’s prompt, make sure to explicitly mention the chosen language to ensure consistent behavior.
## 
[​](http://docs.vogent.ai/platform-overview/agents/config/voice-settings#default-voice)
Default Voice
Select the voice that your agent will use by default. Each voice has been optimized for natural conversation and clear pronunciation, and certain voices have been optimized for spelling. For more information on voices, check out the [Voices](http://docs.vogent.ai/platform-overview/voices) page.
The default voice can be overridden on a per-call basis using the API if needed.
## 
[​](http://docs.vogent.ai/platform-overview/agents/config/voice-settings#volume)
Volume
Fine-tune your agent’s speaking volume to ensure optimal audio levels for different scenarios. The volume scale includes:
  * Quietest
  * Quieter
  * Normal (recommended default)
  * Louder
  * Loudest

This setting is particularly useful when your agent needs to adapt to different environmental conditions or caller preferences.
## 
[​](http://docs.vogent.ai/platform-overview/agents/config/voice-settings#pronunciation-config)
Pronunciation Config
Customize how your agent pronounces specific words or phrases. This is especially useful for:
  * Brand names
  * Product names
  * Technical terms
  * Industry-specific terminology
  * Location names


Pronunciation configurations are applied globally to all of your agent’s conversations.
